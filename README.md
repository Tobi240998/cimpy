Dieses Repository enthält die im Rahmen einer Masterarbeit entwickelte Implementierung eines LLM-basierten Kommunikationsagenten für die Analyse historischer CIM-Daten und die Interaktion mit DIgSILENT PowerFactory. Das System unterstützt sowohl eine Multi-Agent-Architektur mit Router- und spezialisierten Domain-Agenten als auch eine zentralisierte Single-Agent-Architektur. Beide Ansätze können hinsichtlich Qualität, Fehlerraten und Effizienz verschiedener Sprachmodelle miteinander verglichen werden.

Multi-Agent-System starten: llm_routing.run_router

Single-Agent-System starten: single_agent2.llm_routing.run_router
